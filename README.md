# 그림자 소녀 (Shadow Girl)

pico2d 로 만든 횡스크롤 액션 플랫포머. 어둠이 깔린 숲을 지나 빛의 문까지
달려가며 슬라임과 위습을 쓰러뜨리고 코인을 모은다.

## 실행

```bash
python main.py           # 게임 실행
python main.py --smoke   # 약 7초 자동 동작 테스트 후 종료
```

필요한 패키지는 `pico2d` 하나뿐이다(pip install pico2d).

## 조작

| 키 | 동작 |
| --- | --- |
| `A` / `D` 또는 `←` / `→` | 이동 |
| `SPACE` / `W` / `↑` | 점프 (짧게 누르면 낮게 뜀) |
| `J` / `X` / `K` / `LCTRL` 또는 마우스 왼쪽 버튼 | 공격 |
| `P` | 일시정지 / 해제 |
| `R` | 재시작 |
| `ESC` | 종료 |

## 게임 규칙

- 코인 1개 10점, 적 처치 100점, 적을 밟고 튀어오르면 150점.
- 회복 아이템은 하트를 1칸 채우고, 이미 가득 차 있으면 50점이 된다.
- 구멍에 빠지면 하트 1칸을 잃고 마지막 체크포인트에서 다시 시작한다.
- 빛의 문에 도달하면 클리어. 남은 시간에 따라 보너스 점수가 붙는다.
- 하트 5칸을 모두 잃으면 게임 오버.

## 파일 구성

| 파일 | 설명 |
| --- | --- |
| `main.py` | 월드(발판·코인·적·체크포인트·골), 카메라, 이펙트, HUD, 화면 상태 |
| `girl.py` | 플레이어 캐릭터 클래스 `Girl` — 물리, 상태 머신, 스프라이트 재생 |
| `idle_sprite.png` | 대기 / 달리기 |
| `jump_sprite.png` | 점프 상승 / 하강 |
| `attack_sprite.png` | 공격 |
| `hit_sprite.png` | 피격 |
| `retire_sprite.png` | 사망 |

## 스프라이트 시트 규칙

모든 시트는 `1536x1024` 이고 **5열 × 2행(10프레임)** 이다. 프레임 한 칸은
약 `307x512` 이며, 화면에는 `0.38` 배로 줄여서 그린다. 캐릭터는 오른쪽을
바라보는 그림이라 왼쪽으로 갈 때는 가로로 뒤집는다.

시트마다 셀 아래쪽 여백(발이 셀 바닥에서 떨어진 정도)이 달라서
`girl.py` 의 `FOOT_PAD` / `RETIRE_PAD` 에서 보정한다. 이 값을 바꾸면
발이 땅에 붙는 높이가 달라진다.

## 참고

- 떠 있는 발판은 단방향 발판이라 아래에서 점프해 통과하고, 위에서만 딛는다.
- `pico2d.draw_circle` / `draw_rectangle` / `draw_line` 은 정수 인자만 받기
  때문에 `main.py` 의 `patch_draw_primitives()` 에서 실수를 정수로 바꿔
  넘기도록 감싼다.
- 도형에 알파를 적용하려면 `enable_alpha_blending()` 이 필요하다.
